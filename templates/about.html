Project documentation

About the project

A final-year academic demonstration of supervised learning for customer booking completion.

Problem statement

Use historical booking attributes to estimate whether a booking will be completed. The target column is booking_complete, with 0 representing not completed and 1 representing completed.

Algorithm

Random Forest Classifier with 100 trees. The model was trained using numerical features plus one-hot-encoded categorical features.

Preprocessing

The app maps weekdays to numeric values and uses one-hot encoding with the same drop_first=True approach as the notebook. Encoded columns are aligned to the saved model's expected feature names.

Limitations and responsible use

This is an educational model trained on a specific dataset. Its predictions may not generalize to live BA operations. Do not use it for actual operational, financial, or customer decisions without validation, governance, and appropriate authorization.
